# The Vault launch film

**The Vault: Make your case** is a 45-second, 1080p motion-graphics launch film for Flow State.

- 0–9s: introduce the bank and its characters
- 9–18s: show movement, conversation, and the player’s turn
- 18–31s: explain ArmorIQ’s identity, policy, signed-plan, and approval boundaries
- 31–37s: credit ElevenLabs for character voices
- 37–45s: close on the allowed, held, and blocked outcomes and sponsor roles

The narration was generated in one ElevenLabs request (451 characters). The visuals use the actual UI from the recorded live run; this is an edited launch film, not an uncut gameplay recording. The sequence is motion-graphics composition over authentic game screenshots, with captions and a music bed.

Files:
- `the-vault-launch.mp4` — final film
- `captions.srt` — timed narration captions
- `voiceover.txt` — narration script
- `poster.jpg` — cover frame
